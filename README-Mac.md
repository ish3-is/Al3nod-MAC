# تشغيل ISHARA على Mac M1 / M2 / M3

هذه النسخة تُبنى على جهاز Apple Silicon حقيقي داخل GitHub Actions باستخدام
`macos-15` وPython 3.11، ثم تُسلَّم كتطبيق مستقل. مستخدمة Mac **لا تحتاج إلى
تثبيت Python أو pip أو أي مكتبات**.

## أولًا: بناء النسخة من GitHub

1. ارفع مجلد مشروع ISHARA كاملًا إلى مستودع GitHub مع الحفاظ على المسارات.
2. تأكد من وجود ملف النموذج:
   `ai/models/sli-sentences-phone-v1.onnx`.
3. من صفحة المستودع افتح **Actions**.
4. اختر **Build ISHARA for macOS Apple Silicon**.
5. اضغط **Run workflow** ثم **Run workflow** مرة أخرى.
6. بعد نجاح جميع الخطوات، افتح تشغيل الـ workflow ونزّل Artifact باسم
   **ISHARA-macOS-M2**.
7. فك ضغط Artifact؛ ستجد داخله `ISHARA-macOS-M2.zip` وتقريرَي الاختبار.

ملف ZIP الداخلي أُنشئ بواسطة `ditto` للمحافظة على بنية `ISHARA.app` والروابط
والخصائص الخاصة بنظام macOS.

## تشغيل التطبيق على جهاز Mac

1. فك ضغط `ISHARA-macOS-M2.zip` بالنقر المزدوج.
2. انقل `ISHARA.app` إلى مجلد **Applications**.
3. في أول تشغيل، انقر على التطبيق بزر الفأرة الأيمن واختر **Open**، ثم اضغط
   **Open** في رسالة macOS.
4. إذا لم يظهر خيار Open، افتح:
   **System Settings > Privacy & Security**، ثم ابحث عن رسالة حظر ISHARA
   واضغط **Open Anyway** بعد التأكد أن الملف نُزّل من مستودع المشروع الصحيح.

لا تُعطّل Gatekeeper ولا تستخدم أمرًا يعطّل حماية النظام بالكامل. التطبيق
موقّع بتوقيع ad-hoc لضمان سلامة بنية الحزمة، لكنه غير موقّع بشهادة Apple
Developer ID وغير موثّق عبر Apple Notarization؛ لذلك قد يعرض macOS تحذيرًا في
أول تشغيل.

## صلاحية الكاميرا

عند طلب التطبيق للكاميرا اختر **Allow**. إذا رُفض الطلب سابقًا:

1. افتح **System Settings**.
2. انتقل إلى **Privacy & Security > Camera**.
3. فعّل ISHARA.
4. أغلق التطبيق وافتحه من جديد.

أغلق FaceTime وZoom وTeams والمتصفح إذا كانت الكاميرا مستخدمة من تطبيق آخر.
يمكن اختيار كاميرا خارجية بتشغيل التطبيق بعد ضبط `ISHARA_CAMERA_INDEX`، لكن
الوضع الافتراضي يجرب الكاميرات 0 ثم 1 ثم 2 تلقائيًا.

## بيانات الدخول التجريبية

- Username: `cashier`
- Password: `Ishara@2026`

تُنشأ قاعدة البيانات محليًا في:
`~/Library/Application Support/ISHARA/ishara.db`، ولا يحاول التطبيق الكتابة
داخل حزمة `ISHARA.app`.

## ما الذي يتحقق منه GitHub Actions؟

- أن runner ومعالج التطبيق `arm64`.
- استيراد PySide6 وOpenCV وMediaPipe وONNX Runtime وNumPy.
- تنفيذ الاختبارات الآلية التي لا تحتاج كاميرا فعلية.
- وجود النموذج والقاموس وملفات SF1 والصور داخل الحزمة.
- تحميل نموذج ONNX من داخل `ISHARA.app`.
- تنفيذ استدلال فعلي بمدخل SF1 اصطناعي صحيح الأبعاد `[1, 15, 356]`.
- وجود `NSCameraUsageDescription` في `Info.plist`.

هذا الاختبار يثبت سلامة التجميع ومسار الاستدلال، وليس دقة التعرّف. GitHub
Actions لا يوفر كاميرا Mac فعلية، لذلك لا يدّعي التقرير اختبار بث الكاميرا.

## التشغيل دون إنترنت

بعد تنزيل التطبيق لا يحتاج ISHARA إلى الإنترنت؛ نموذج ONNX والقاموس وملفات
المعالجة مضمّنة داخل الحزمة. لا توجد مفاتيح API أو كلمات مرور خارجية في عملية
البناء.

## ملاحظة الترخيص والنشر العام

ملف النموذج تابع لمصدر DF-Team/sli-sentences ورخصته الموثقة في المشروع
`CC BY-NC-SA 4.0`، وكود المرجع `MIT`. قبل جعل المستودع عامًا، راجع
`AI_MODEL_INTEGRATION.md` والتزم بنسبة العمل للمصدر والاستخدام غير التجاري
وشروط المشاركة بالمثل. يمكن إبقاء المستودع خاصًا وتشغيل GitHub Actions عليه.

## هل يمكن تشغيل التطبيق من GitHub مباشرة؟

لا. GitHub Pages يشغّل مواقع ويب فقط ولا يستطيع تشغيل تطبيق Python مكتبي أو
الوصول إلى كاميرا المستخدم بهذه المعمارية. GitHub Actions يبني التطبيق، وبعدها
يمكن توزيع ZIP من Artifacts أو GitHub Releases، بينما التشغيل الفعلي يكون
محليًا على جهاز Mac.
